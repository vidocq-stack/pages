The Vidocq site is now live.

We wanted a publication flow that stays simple, transparent, and close to the code.
Roq gives us exactly that: content written as plain AsciiDoc files, tracked in Git, published as a static site.

The site has two roles.

The link:/[home] and link:/projects/[projects] pages present the Vidocq ecosystem:
what each sub-project does, how the layers compose, and what design constraints shape every decision.
The link:/contributing/[contributing guide] covers prerequisites and workflow for anyone who wants to get involved.

The link:/blog/[blog] is where we publish technical updates:

* release notes for the different Vidocq sub-projects,
* architecture and implementation notes,
* migration guides when breaking changes happen.

If you build with Vidocq, this is the feed to watch.
